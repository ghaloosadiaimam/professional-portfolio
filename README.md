# Sadia Imam - IT Portfolio

A responsive portfolio built with HTML, CSS and JavaScript, deployed on Vercel.

## Files
- `index.html` - page content
- `style.css` - layout and colors
- `script.js` - footer year
- `assets/cv.pdf` - downloadable CV (add your own file here)

## Run locally
Open `index.html` in a browser.

## Deploy
Push to GitHub, import the repository in Vercel, set Framework Preset to Other and deploy.
